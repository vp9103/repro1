# audit P1.4 coverage impact — what the 2026-10-04 term pass asks of the topics

Written 2026-10-04 in `.repro/ws/P1_4/`. The pass changed the terms of 348 of the 396 TOPIC-MAP rows (the other 48 already anchored each
named part and were kept). The second-model coverage review is gone, so these terms are the only gate check that a topic teaches an
objective. This file says, row by row, what each accountable (first-listed) topic still has to contain.

## Method

A temporary root combined a copy of `fast/content/` (the current fast-track content: rp1-rp30 and en1, en2, en5, en6, en7, en9) with this
workspace's `scope/`. For every topic the gate's own function `check_repro.coverage_terms_problems(ct, tid)` ran against it (`rc.topic_map_rows`
and `rc.blueprint` pointed at the temporary `scope/`). Only the TOPIC-MAP lines of the changed rows are listed. A term counts as present when
it is a lowercase substring of the topic's rendered text, as in the gate. Endocrine topics en3, en4, en8 and en10-en18 are not written yet, so all
of their new terms are listed as missing. No term kept from the old map is missing in any written topic (checked), so the missing terms below are
all new requirements.

## YIELD values the topics must copy

- `fast/content/topics/rp29.json`: `exam` `mid` must become `hi` (`yld` stays `lo`).

All other written topics already match the table.
