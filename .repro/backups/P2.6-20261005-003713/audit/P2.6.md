## 2. The self-test (`?selftest=1`, F37)

**Its verdict now means something.** Before, `R.ok` went false only when a section threw, so the stub read
`ok: true` with `auditListsEmpty: false` (P2.2 §3 c). At the end of the run, `must()` now checks the invariants the
report exists to prove and pushes `assert <name>: <detail>` into `errors`:
- `auditListsEmpty` is true (the detail names each non-empty list and its length);
- `viewFailures` is empty;
- each extra hook that found material in the content proved its case: `conceptThreads` (the seeded tag is listed and
  its label and home heading are on the page), `errorTypes` (`classified`), `fatigue` (`shown`).

A hook that finds no material for its case in the loaded content returns `skipped` with the reason, which is not a
failure. So the same code is green on the stub, on stub-partial and on a block mid-wave, and it fails on a real
defect (the negative test above).
