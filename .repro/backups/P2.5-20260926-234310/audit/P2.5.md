## 3. Probe fields versus the contract (orchestrator note 2)

I found no field that measures something other than its §8 contract. Two things are worth knowing:
- **`probe400.figs.lightbox.afterFitGlyph` is null at narrow widths.** The DOM contract names a "Fit" button. Where
  fitting would shrink a figure below its own width (any phone), the cardio P6 fix relabels the button "Actual size",
  and it returns to 100 %. The probe finds no /fit/ button there, and the gate accepts null. I kept the label: calling
  it "Fit width" would be untrue at that width. At 1280 the button reads "Fit width", and `afterFitGlyph` is 18.07.
- **`state.confusionsHasRapidKind` seeds the pick text "probe-pick", which is not an option.** The rapid rule counts
  any recorded wrong pick text, because picks are stored by text and survive the option shuffle. It does not require
  the text to still be a current option, so the field passes on real behavior, not a special case.
