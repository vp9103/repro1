## 2. The script (`engine/extract_engine.py`)

`python engine/extract_engine.py --src engine/base/cardio-source.html --out engine/base` writes `shell.html`,
`engine.js`, `selftest.js` and `REGIONS.json`.

**How regions are cut**
- Every region is a row with an exact-substring anchor, searched in order, each after the previous match. No line
  numbers are used.
- A region starts at the line of its anchor. If the anchor sits inside a banner comment, the region starts where that
  comment opens.
- Each region runs to the next region's start, so the regions tile the file.

**Fail-loud (exit 1, nothing written)**
- An anchor is missing, out of order, or on the same line as another.
- A column-0 statement is not allowed by its row. Each statement (declaration, IIFE, call, assignment) is matched
  against the row's allow patterns. Engine rows allow functions and lower-case bindings. ALL-CAPS maps, IIFEs,
  calls and assignments must be named explicitly.
- A literal substitution finds the wrong number of matches.
- `engine.js` would re-declare a global that build.py emits, or the shell lacks a placeholder.

I tested each failure on scratch copies of the source, and each one exited 1 with the reason:
- a renamed banner (missing anchor);
- a new IIFE in an engine region;
- a new `const Q_POINT` map in an engine region;
- a function inside a content region;
- a changed literal.

A CRLF copy extracts the same regions (CRLF is read as LF).

**Deterministic.** The outputs contain no paths and no timestamps. The same bytes came out when the source path was
given in different forms, and the gate's re-run reproduces all four outputs.

**Regions: 160** (ENGINE 49, CONTENT 66, PATCH 25, LITERALS 20, MIXED 0). They follow ENGINE-MAP §1a rows 1–127, with
these differences:

- Where one ENGINE-MAP row mixed engine code with content or patch code, it is split so that every region has one
  class. Rows split this way: 13/15/16/18 (the registry declaration, which build.py now emits, is separate from the

As a result, MIXED is not needed. Each region records its anchor, lines, sha of the source text and its top-level
