# P1.2 Lecture material (operator)

## What was done

1. **Approval.** On 2026-09-26 the user wrote in chat: "I approve downloading my Canvas course files listed on FILE
   lines in scope/CANVAS-SCOPE.md (about 700 MB) and the BiCEP "Learning objectives" documents into
   C:\Users\varsh\repro-endo-path\lecture-src\, for this study tool only." and "No need to ask me for any
   permissions". Only the 51 FILE-line files were downloaded, only into `lecture-src/` (project root, untracked, not
   the workspace).
2. **Download (read-only Canvas API).** In my own tab of the user's logged-in Chrome I read `GET /api/v1/files/<id>`
   for all 51 ids (all HTTP 200, none locked, 600,204,328 bytes in total), then `GET /api/v1/files/<id>/public_url`
   for each. That returns Canvas's own short-lived (24 h) signed inst-fs download link, which `curl -L -o` saved to
   `lecture-src/<id>.<ext>`. Every saved size equals the size the files API reported. The signed links were kept
   only in a temp folder outside the project and deleted after use; no cookie, password or key was copied. No form
   was submitted, no quiz opened, no message sent; the tab was closed at the end.
3. **Extraction** (scripts kept in `%TEMP%\repro-P1_2\`, none in the workspace):
   - `.pptx` (23 extracted of 24): `zipfile` + ElementTree. Slide order from `ppt/presentation.xml` (`sldIdLst`), each slide's
     `<a:t>` runs in shape-tree order (group shapes, tables as Markdown tables, SmartArt text from
     `ppt/diagrams/data*.xml`), speaker notes from the linked `ppt/notesSlides/*.xml` body placeholder under
     `Notes:`. Headings are `## Slide N: <title>` with the real slide number, so a gap in the numbers is an
     image-only or boilerplate slide. Dropped: title slides, disclosure slides, "Questions?"/"Thank you" slides,
     slides with no text, footer lines repeated on 40 % or more of slides, and notes that only repeat the slide text.
   - `.pdf` (25 extracted of 26): PyMuPDF page text under `## Page N`. Dropped: a short title page 1, short disclosure pages,
     lines repeated on 40 % or more of pages (running headers and footers), bare page numbers; ligatures and soft
     hyphens normalized. The three Pediatrics in Review PDFs (70351/23484186, /23484246, /23484249) use
     custom-encoded math fonts whose symbols come out as control characters; each (file, font, code) was rendered,
     read off the image and mapped (for example 3β-hydroxysteroid dehydrogenase, μg/dL, 14±1 SD days, >3.0 mL,
     <4 mL, ≤5 cm).
   - Symbol / Wingdings private-use characters (pptx and pdf) are mapped to what they draw (↑ ↓ → ✓, bullets,
     Symbol "b" = β); no private-use or control characters remain in any lectures file.
   - `.docx` (1 file): python-docx paragraphs (headings as `###`, list items as `- `) and tables in body order.
   - Every file starts with `# Source: <course>/<file> | <file name> | session <CODE>` and a line with the session's
     week, date and title from CANVAS-SCOPE.md and what was kept or omitted.
   - Privacy: e-mail addresses (faculty contact lines) and phone numbers are removed; the text was searched for
     Zoom links, rosters, team/group lists and grades and none are present.
4. **Result.** 49 of 51 files extracted (96 %), all at 150 words or more (smallest: 70351/23274306, 399 words); two
   SKIP rows with reasons in `scope/LECTURE-FILES.md`, which also indexes every file (status, session, type, words).

## Decisions

- **CDC STI Treatment Guidelines 2021** (MMWR RR-70-4) is posted twice (70351/23568845 under PATHPHARM-CERVIX-HPV and
  70351/23479458 under VIRAL-STI-TORCH); the two files are byte-identical (same MD5). The text is extracted once,
  in `70351_23568845.md`, and the copy is a SKIP row pointing to it. The extraction keeps pages 1-137 (all clinical
  text) and stops at "Conflicts of Interest": the reference list, work-group member roster and back matter (pages
  137-192) are omitted, which is stated at the end of the file. It is still about 100,000 words: search it, do not
  read it end to end.
- **pap smear presentation sim.pptx** (70351/23274426) is a SKIP: 9 slides with about 40 words of slide text; the
  rest are UpToDate figure screenshots. I viewed the images; they were not transcribed because they are
  third-party figures and the screening table in them (ACOG 2016, ACP 2015, ACS/ASCCP/ASCP 2012) predates current
  guidance.
- Canvas names for four ENDO files differ from the descriptive names in CANVAS-SCOPE.md: 70371/23196976,
  /23196866 and /23196915 are PDF exports of Dr. Richards' decks ("Endocrine Pharmacology I/II/III", CI MED Class of
  2028 file names), and 70371/23192282 is "Applications Type 2 Diabetes TBL -rev3 (1) (3).pdf". The lectures files
  keep the CANVAS-SCOPE.md names so they match the FILE lines.
