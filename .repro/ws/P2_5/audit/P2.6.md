## 2. The self-test (`?selftest=1`, F37)

**Its verdict now means something.** Before, `R.ok` went false only when a section threw, so the stub read
`ok: true` with `auditListsEmpty: false` (P2.2 §3 c). At the end of the run, `must()` now checks the invariants the
report exists to prove and pushes `assert <name>: <detail>` into `errors`:
- `auditListsEmpty` is true (the detail names each non-empty list and its length);
- `viewFailures` is empty;
- each extra hook that found material in the content proved its case: `conceptThreads` (the seeded tag is listed and
  its label and home heading are on the page), `errorTypes` (`classified`), `fatigue` (`shown`).

A hook that finds no material for its case in the loaded content returns `skipped` with the reason, which is not a
failure. So the same code is green on the stub, on stub-partial and on a block mid-wave, and it fails on a real
defect (the negative test above).

**Seeded from the loaded content (no cardio literals left):**

| Section | Before | Now |
|---|---|---|
| threads hook | Seeded questions only, on the tag with the widest spread whether or not it had a home. On the stub, questions give only 2 misses on any cross-topic tag, so nothing was listed (`listed: []`) and the section proved nothing. | Seeds from every channel `conceptThreads()` counts: questions, then rapid items, then drills. It uses only tags with a `CONCEPT_HOME` entry (the others can never thread), and picks the tag that crosses the most topics, then the one with the most items. It seeds the plan's floor exactly: two misses in one topic and one in another. Topics with more single items come first, because a drill run counts at most 3 misses over up to 12 attempts. Stub: `feedback-logic`, seeded `q:rp8q03`, `r:rp8r01`, `q:en5q03`; listed `["feedback-logic"]`; pointer rendered. |

| `spotWrongNotes` | Counted images with 3 or more `ww` notes (the cardio wrong-label count) | Counts images whose every `wrong` label has its own note, and lists the others |
| `a11y`, `a11yFeedback` | Threw on a bank with no question, rapid item, sort drill or image | That half reports `skipped: no …` |
| `reviewShareAtPace14`, `lateResetBudgetRatio` | Threw on content with no `PATH` (`todaysPlan` reads the current stage) | Return `skipped: no stages yet` |
| `\bcorrect\b` in two a11y regexes | The cardio source carried literal backspace characters (0x08) where `\b` was meant, so "correct" never matched | Real word boundaries |
