# Practice-item audit E: rp15, rp16, rp17, rp18, rp21, rp22, rp23

Auditor: fresh Claude, 2026-10-06. Not a phase verdict; no token. Nothing but this file was written.

Method
- Read in full, field by field (s, l, o, a, e, w, et, bl, pt.say for questions; q, o, a, x, w, pt.say for rapid; key, items, whys for drills): fast/content/questions/<tid>.json (86 items), fast/content/rapid/<tid>.json (109 items) and fast/content/drills/d_<tid>_*.json (7 drills, 94 drill items), 202 objects in all.
- Each item was judged against the current lesson fast/content/topics/<tid>.json (read in full, R1 and R3 repairs included), scope/STEP1-BLUEPRINT.md, and First Aid, Pathoma, Robbins and Costanzo; dated guidance where an item uses it (CDC 2021 STI guidelines, HHS perinatal HIV guidelines, ACOG GBS and HSV guidance, Endocrine Society testosterone guideline).
- Rewording damage was checked with an item-by-item diff against the version before the practice pass (git 158eac3^ for rp15 to rp21, 6e52424^ for rp22 and rp23) and against the P02 and P03 notes.
- "On the page now": the QS, RAPID, DRILLS and DRILL_WHY data embedded in fast/repro-endo-path.html were parsed and compared with the content files: all 202 objects are identical, and every flagged string below is present on the page. Every pt.hl label exists in its figure, and each pt.say was read against that figure's text.
- Kinds: ERROR (a wrong fact or causal claim), KEY (key not the single best answer as worded), NON-STEP1, NOT-TAUGHT (not taught in this topic's lesson), WORDING, GIVEAWAY.
